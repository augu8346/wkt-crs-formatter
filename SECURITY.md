# Security

Report issues against the latest preview. Formatting runs locally; it should not execute or upload input. Use a synthetic CRS, remove private names and paths, and never post tokens, credentials, or sensitive data.

Use GitHub's **Security > Report a vulnerability** on this repository for private disclosure. If unavailable, open a public issue asking the owner to enable private reporting, without describing the vulnerability. Maintainers should reproduce privately, update affected dependencies or parser code, rerun tests, and rebuild the VSIX.
